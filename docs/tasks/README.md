# Task packets

Optional local work packets when no issue tracker supplies an adequate task. Inbox captures requests; ready holds complete execution contracts; completed preserves useful decisions/evidence, not a substitute for live Git/PR state. Folder placement alone never makes a blank task READY.

A small task can remain in the user request or PR; no duplicate issue tracker is required. Link the one canonical task/issue and use [the ready packet](../templates/ready-packet.md) only when scope or handoff needs it.
