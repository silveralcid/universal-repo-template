# Proportional work and context cost

**Owner:** keeping agent work useful, bounded and inexpensive without weakening acceptance.

Routine fix: live-state check, relevant owner, direct edit, targeted verification, concise report. No mandatory research dossier, execution plan, subagent or durable test report.

Feature: compact ready packet, one vertical slice, scoped tests, relevant integration evidence, updated owner docs. Use a plan only for real dependencies or multiple sessions.

Research: state question, relevance and decision it could inform, start with existing records, seek disconfirming evidence, stop when the evidence supports a useful conclusion or names the remaining uncertainty. Unknown relevance is allowed; an agent must not manufacture applicability.

Parallel work: bounded independent scopes, clear write ownership, one integration owner, no more workers than benefit justifies. A blocked dependency is sequenced, not simulated by racing two agents at shared files.

Preserve narrow loop evidence, not every command transcript. Use a stronger model or specialist only when uncertainty/rework risk justifies it; no model names or provider hierarchy are baked into project authority. Avoid repeating the full suite after each keystroke. Do not suppress necessary integration tests to look efficient.
