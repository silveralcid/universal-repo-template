# Agent area guides

Each generated guide points to **one** canonical area specification and lists owned paths, adjacent boundaries, and narrow verification slots. The guide is routing metadata, not competing product authority. Use `python tools/repo.py area list` and `python tools/repo.py context --topic area:<id>`; read only your task's area and directly touched neighbors.

Create areas with `python tools/repo.py area new`; do not hand-copy a guide and forget to register its tests, context route, or owner index.
