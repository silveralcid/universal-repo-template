# Contracts and unresolved boundaries

Create a focused contract only when a real subsystem boundary exists: data/schema, API/event, persistence, agent/tool permission, workflow ownership or another cross-module agreement. Include owner, status, consumers, invariants, versioning/migration and acceptance.

OPEN contracts contain the precise unresolved decision and safe independent work; they do not authorize guessed defaults in public interfaces or saved state. Accepted contracts link to owning specs/ADRs. Keep examples illustrative unless expressly accepted. There are no preinstalled application contracts in this template.
