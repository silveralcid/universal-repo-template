# implement-task

Inspect current task, actual branch and the owning docs/code. Verify a ready packet against live evidence rather than repeating completed research. Follow docs/agents/definition-of-done.md and docs/engineering/VERIFICATION.md. Implement the smallest coherent behavior including the actual entrypoint; reuse existing owners. Add targeted success/failure checks and inspect changed contracts. Update the owning documentation in the same change. For multi-session work use PLANS.md and scoped lane ownership. Do not convert research into product authority or add unrequested abstractions. Run applicable checks, report exact results/unrun checks and mark mocks/placeholders. Deliver the authorized branch/PR or a usable local diff; no merge/deploy/external mutation without explicit authorization. Stop retry loops that add no evidence and continue independent work when one boundary is blocked.
