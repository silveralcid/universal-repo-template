# project-bootstrap

Read START-HERE.md and docs/agents/startup.md. Inspect live instructions, dirty state and existing stack first. Extract the user request into docs/project/BRIEF.md only as needed. Reuse existing architecture; in a blank project choose only the minimal stack justified by the goal. Make reversible decisions and proceed; escalate material irreversible uncertainty. Set actual commands in .repo/project.json and an area guide only for a real subsystem. Use scoped local setup after inspecting scripts, never a global/cloud install by default. Do not stop at scaffolding: hand off into implement-task and deliver the first runnable verified slice. Follow delivery authorization, preserve unrelated work and report unavailable tools without inventing success.
